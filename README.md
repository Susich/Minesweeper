# САПЁР — Cyber Sapper

2D-игра-головоломка «Сапёр» в стиле киберпанкового HUD-консоли.
Проект разработан в рамках курса «Технологии разработки программно-информационных систем»
(Волгоградский государственный технический университет, ВолгГТУ).

Игрок работает оператором-сапёром: вскрывает ячейки минного поля, расставляет флаги по
числовым подсказкам и обезвреживает сектор за минимальное время.

## Возможности

| Раздел | Возможности |
|---|---|
| **Игровое поле** | Матрица квадратных ячеек 9×9 / 16×16 / 30×16, а также произвольный размер (ширина 9–30, высота 9–24). Каждая ячейка имеет три визуальных состояния: закрытая, вдавленная (при зажатии ЛКМ) и открытая. |
| **Безопасный первый ход** | Мины генерируются только после первого клика; выбранная ячейка и 8 её соседей гарантированно чисты (FR-003…FR-005). |
| **Каскадное раскрытие** | Пустые области вскрываются алгоритмом BFS до границ чисел (FR-007). |
| **Флаги и аккорд** | ПКМ ставит/снимает флаг, СКМ или одновременные ЛКМ+ПКМ вскрывают соседей вокруг числа (FR-008…FR-010). |
| **Таймер и счётчик мин** | Таймер в формате `000`–`999`, счётчик показывает «всего мин − установлено флагов», при перерасходе уходит в минус (FR-014…FR-017). |
| **Условия победы и поражения** | При победе остальные мины автоматически помечаются флагами, при поражении показываются все мины, а неверные флаги перечёркиваются (FR-018…FR-021). |
| **Таблица рекордов** | Топ-5 по каждому уровню, вкладки по сложности, сброс рекордов (FR-022…FR-025). |
| **Особые параметры** | Ручной ввод высоты, ширины и количества мин с автоматической валидацией диапазонов (FR-012…FR-013). |
| **Звук** | Клик, флаг, взрыв, фанфара, тиканье таймера; регулировка громкости и режим «Без звука» (FR-029…FR-034). |
| **Сохранение сессии** | Незавершённая партия сохраняется локально и восстанавливается при следующем запуске (FR-035…FR-037). |
| **HUD-консоль** | Телеметрическая панель: LED-счётчик мин, индикатор состояния, таймер, системный статусбар с FPS, телеметрия сектора. |

## Управление

| Действие | Клавиши |
|---|---|
| Открыть ячейку | **ЛКМ** |
| Поставить / снять флаг | **ПКМ** |
| Аккорд (быстрое раскрытие соседей) | **СКМ** или **ЛКМ + ПКМ** |
| Быстрый рестарт | **F2**, **Пробел** или клик по индикатору состояния |
| Пауза | **Esc** или кнопка «Пауза» |
| Полноэкранный режим | **F11** |
| Выход из приложения | Меню «Справка» → «Выход из приложения» |

## Запуск готовой сборки

1. Скачайте архив `CyberSapper-v1.0.0.zip` из раздела **Releases**.
2. Распакуйте его в любую папку.
3. Запустите **`CyberSapper.exe`**.

> При первом запуске Windows может показать предупреждение SmartScreen («неподписанное
> приложение») — сборка собрана локально и не подписана сертификатом. Нажмите
> **«Подробнее» → «Выполнить в любом случае»**.

Настройки, рекорды и незавершённая партия сохраняются в
`%APPDATA%\VolgGTU\CyberSapper\`.

## Сборка из исходников

**Требования:** Unity **6000.3.28f1** (или новее из ветки 6000.3), Visual Studio / Rider.

```bash
git clone https://github.com/Susich/Minesweeper.git
cd Minesweeper
```

Откройте папку проекта в Unity Hub и дождитесь импорта ассетов.

**Сборка сцены.** Вся HUD-сцена генерируется кодом, а не рисуется руками:

```
Tools → Build Cyber Minesweeper Scene
```

**Сборка исполняемого файла:**

```
Tools → Build Windows Standalone
```

Готовый плеер появится в `Builds/CyberSapper.exe`.

**Запуск модульных тестов ядра:**

```
Tools → Run Unit Tests
```

Тестовый набор покрывает генерацию поля, безопасный первый ход, расчёт соседей,
каскадное раскрытие, флаги и счётчик, условия победы и поражения, аккорд,
валидацию пользовательской сложности и таблицу рекордов.

## Архитектура

Проект построен по схеме **MVC + Observer** в соответствии с ограничениями SRS (раздел 2.4):

```
InputSystemUIInputModule
        │  (ЛКМ / ПКМ / СКМ)
        ▼
    CellView  ──►  GameController  ──►  MinesweeperBoard      ← ядро, без Unity API
        ▲              │  │
        │              │  └──►  SaveManager  ──►  JSON в %APPDATA%
        │              ▼
        └── events ───►  HeaderStatusView / StatusFaceButton /
                         SettingsModal / LeaderboardsModal /
                         VictoryModal / DefeatModal
```

**Ядро (`Minesweeper.Core`)** не зависит от UnityEngine и полностью покрывается
юнит-тестами: генерация мин, подсчёт соседей, каскадное раскрытие, флаги, аккорд,
условия победы/поражения, валидация сложности.

**Представления (`Minesweeper.UI`)** подписываются на события `GameController`
(`OnCellUpdated`, `OnTimerChanged`, `OnMineCounterChanged`, `OnGameStatusChanged`,
`OnGameInitialized`) и не содержат игровой логики.

**HUD-сцена генерируется кодом** (`CyberMinesweeperSceneBuilder`), а не редактируется
вручную: весь интерфейс выражен в дизайн-сетке 1600×900 и умножается на `UI_SCALE = 1.2`,
чтобы попадать точно в нативные 1920×1080 без пересэмплирования.
